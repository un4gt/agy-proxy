# CLI 原生传输：session 隔离与实时内容验证

2026-10-18，在本地临时 Docker 容器测试，未改线上或启用生产路由。

本文记录第二阶段状态。后续已增加默认关闭的 Chat Completions 后端、Write 返回长度校验和 pi 验收，见 [pi 接入报告](native-chat-pi-20261018.md)。

## 结果

真实 CLI 原生发包、FIFO 旁路读取、多个独立 session 的多轮并发与单边取消已通过本轮验证。每个会话拥有独立 CLI/GDB、二进制与符号快照、工作目录、三条 FIFO、队列、锁和请求映射。认证 owner 与外部 session ID 一起决定复用范围，配置改变会重建，忙会话拒绝重复占用。

| 验证 | 本次结果 |
|---|---|
| 不同 owner 使用相同外部 session ID | 不同 CLI PID 和 conversation ID |
| 两个会话并发首轮、反序多轮回忆 | 各自仅返回自己的随机标记，进程及 conversation ID 保持稳定 |
| A 已收到原始文本时取消，B 继续请求 | A 的 CLI/GDB 消失，B 完成第三轮并保留自己的上下文 |
| 关闭全部 session | 已知 CLI 进程全部消失 |
| 长文本正文 | 56 个实时片段，拼接后与 CLI 最终正文一致（忽略末尾换行） |
| 外部工具请求与回填 | 受限 finish 提交 `lookup_local_marker`，模拟客户端结果回填后返回指定标记 |
| 原始 finish 参数 | 去除 CLI 显示字段后与 CLI structured_output 一致，并通过现有工具契约校验 |

离线测试覆盖：不同 owner/不同 session ID 的隔离、同会话复用、配置更换、忙会话冲突、启动期间占用、容量限制、取消与启动失败清理、辅助/过期请求过滤，以及 HTTP/1.1 keepalive、分片 HTTP 内容、HTTP/2 交错 stream 和 HEADERS/CONTINUATION 的请求关联。原有 headless session 回归也通过。

## 同次调用的时序

长文本首段原始响应在请求开始后约 **9.963 秒**出现，CLI 首个文本增量在 **9.981 秒**出现，最终 result 在 **21.773 秒**出现。

- 原始首段领先最终 result 约 **11.810 秒**。
- 原始首段领先 CLI 首个文本增量约 **18.1 毫秒**。

这证明避免等待完整结果可以明显提前长回答的首次交付；它不证明原始捕获比 CLI 自带增量快 11 秒，也不代表模型生成总时间缩短。当前生产统一执行器会在校验完整候选后才交付正文，原型尚未替换这一逻辑。

工具请求和工具结果两轮都只观察到完整 `finish` 参数，没有普通文本 SSE 增量。其原始 functionCall 分别比最终结果早约 212 和 204 毫秒。不能将普通长文本的提前量外推到现有结构化工具模式。`toolAction`、`toolSummary` 是 CLI 内部显示字段，不能泄漏为外部工具参数。

## 构建身份修正

本地基础镜像的 CLI 1.3.5 会在真实运行后更新为 1.4.0。本轮正式并发、取消、长文本和工具验证使用 1.4.0，SHA-256 为 `60e72242f07c131f75afcd9a9e425d6ee097a1a1b3190ea98ae78fa4180bbfa8`。

原型启动时复制私有二进制与符号文件，核验哈希一致再启动 GDB，防止其他 session 更新安装文件后误用符号地址。第一阶段记录将初始版本号对应到更新后的哈希，现已更正；其普通/捕获运行没有逐次固定构建，因此不作为严格同版本性能对照。

## 尚未完成的生产能力

- 尚未接入 OpenAI/Gemini HTTP 路由，也没有对外开放本原型。
- 现有结构化 finish 的正文增量与客户端工具事件适配仍需设计；原始 functionCall 不能直接透传。
- GDB 会暂停线程；HTTP 解析仍是有限覆盖的原型，不完整支持 trailers、压缩 SSE、关闭连接定界等情况，Write 尚未结合返回值校验部分写入。
- 未验证任意客户端角色历史、工具 schema 向 CLI 网络请求的无损注入；读取响应不消除输入端限制。
- 未做长时间负载、多模型覆盖、异常重试与服务进程崩溃恢复。本轮隔离结论适用于已列出的场景，不是所有情形无串扰的证明。

下一步应优先解决结构化 finish 的增量适配与较低开销的观测机制，再接入可选 HTTP 后端；保持 owner/session 隔离和交付后不自动重试的边界。
