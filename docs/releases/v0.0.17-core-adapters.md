# v0.0.17 core/adapters 拆分

2026-11-12。镜像标签：`tumuer/agy-proxy:core-v0.0.17`、`tumuer/agy-proxy:full-v0.0.17`；`latest` 指向 full。平台仍为 `linux/amd64`，agy CLI 固定 1.4.2。

## 变更

- 仓库拆成两个发行版：`agy-proxy-core`（账号、路由、隔离、store、控制台、bridge、Gemini 协议）与 `agy-proxy-adapters`（OpenAI Chat Completions、Responses、Anthropic Messages）。adapters 精确依赖同版本 core。
- 新增 core-only 镜像：只安装 core，暴露 Gemini API 与控制台；`/v1/chat/completions`、`/v1/responses`、`/v1/messages` 不存在。
- full 镜像保持原有全部协议；`latest` 仍指向 full。
- `GET /v1/models` 在 full 中仍返回 OpenAI 形状；带 `x-goog-api-client: google-genai-sdk/*` 或对应 User-Agent 的 Gemini SDK 请求会内部转到 `/v1beta/models`。core-only 直接提供 Gemini 形状。
- Gemini SSE 不再发送 `: connected` / `: keep-alive` / `: agy-profile` 注释行；keep-alive 改为 `data: {}`，文本改为增量 chunk，最终 chunk 带 `finishReason` 与 `usageMetadata`。
- Gemini 保真补齐：`maxOutputTokens` 映射、`VALIDATED + allowedFunctionNames`、`responseModalities: []`、`responseSchema`/`responseJsonSchema` 互斥与 mime 校验、`functionResponse.parts` 明确 400、`length → MAX_TOKENS`。
- 前端构建输出改为 `core/agy_proxy_core/static/`；控制台不拆分，两个镜像都可用。
- `GET /about` 与 `GET /health` 新增 `edition`（`core` / `full`）；控制台品牌旁显示对应标识。
- 骨架屏改为静态占位，移除 `animate-pulse`，避免账号查询较慢时账号卡片持续闪烁。

## 兼容性

- 数据卷布局不变：`accounts.json`、`data.json`、`bridge-signatures.json`、账号 HOME 与固定 `installation_id` 原样可读。
- `AGY_PROXY_*` 环境变量、8317 端口、`/health`、控制台 URL 不变。
- full 镜像仍保留原端点；core-only 是新部署形态。
- 默认 `docker-compose.yml` 使用 full；`docker-compose.core.yml` 使用 core，两者共用同一组卷。

## 验证

- 容器内 `pytest`：**93 passed**。
- `agy-proxy:core-final`、`agy-proxy:full-final` 构建成功；core 镜像 `import agy_proxy_adapters` 失败，full 成功。
- 两镜像 `/health` 正常；core-only `/v1/chat/completions` 返回 404，full 返回 400（空 body）；`/about` 与 `/health` 的 `edition` 分别为 `core` / `full`。
- 控制台验证：品牌旁显示 `Full` 标识；账号页加载时不再出现脉冲骨架，页面稳定后无持续动画。
- 真实上游：full Chat Completions 返回 `full-ok`；full/core Gemini `generateContent` 分别返回 `gemini-ok` / `core-ok`；core `streamGenerateContent` 返回两个 `data:` chunk，无注释行，最终 chunk 带 `STOP` 与 usage。
- 未推送镜像、未部署线上。

## 回滚

恢复原 Compose 的 `image:` 标签并重建容器即可；新版本不改数据格式，旧镜像可读取新数据。建议保留上一版镜像标签作为回滚窗口。
