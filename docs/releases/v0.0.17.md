# v0.0.17 — 账号模型额度与独立原生实验入口

2026-10-19。正式镜像为 `tumuer/agy-proxy:v0.0.17`，独立实验镜像为 `tumuer/agy-proxy:v0.0.17-native`，平台为 Linux amd64。

## 变化

- 账号 Usage 分别展示可用模型及模型额度、每周／五小时共享额度。上游共享分组只返回 Claude/GPT 时也不会隐藏 Gemini；其中一个查询失败时保留另一部分结果，未知额度不伪造为零。
- 增加默认关闭的原生 Chat 后端及输入清理。Pi 内置工具、MCP、Skills 的既有真实验收材料与复现脚本入库。独立实验镜像包含 GDB、HPACK、固定 CLI 与匹配符号。
- 原生与常规会话共同参与账号迁移／删除保护，防止处理请求时删除账号。原生 CLI 与常规 CLI 分开指定，避免常规更新破坏实验后端。
- 客户端桥接指令明确区分后端环境与客户端工作目录。健康接口增加实际 Chat 后端与输入清理状态。
- 正式镜像从移动的 latest 安装脚本改为官方 CLI 1.4.2 固定 URL 与 SHA-512 校验；原生二进制固定为已验证的 1.4.0 SHA-256。
- 17 篇阶段性报告归入 `docs/archive/`，历史 Windows 注入和中转实验归入 `tools/archive/`；本地二进制、原始证据、缓存不进入 Git 或发布镜像。

## 使用与边界

正式 Compose 默认使用常规后端；升级保留原凭据、密钥、用量和两个数据卷。原生入口使用独立 Compose 项目和数据副本，默认仅监听回环地址，可通过 SSH 转发体验。[部署指南](../deployment.md)与[原生接入指南](../native-backend.md)提供操作步骤。

原生后端仅接管 Chat Completions，仍通过结构化 `finish` 桥接客户端工具；不支持图片，正文／参数仍在完整校验后交付。固定构建之外的 CLI、更多模型及长时间负载仍需进一步验证。常规四协议保持原有能力和边界。
