# v0.0.16 — 统一客户端工具执行与链路诊断

2026-10-15。镜像标签：`tumuer/agy-proxy:v0.0.16`、`tumuer/agy-proxy:latest`；平台与之前版本一致，为 `linux/amd64`。镜像内 AGY CLI 构建校验版本更新为 **1.3.5**。

## 变更

- Chat Completions、Responses、Anthropic Messages、Gemini 共用执行器、工具契约和校验；Gemini 补齐函数声明、调用和结果历史、工具选择与流式往返。
- 工具参数交付前按客户端 Schema 校验。参数修正、符合条件的传输恢复和配额换号共享一次预算；新配置 `AGY_PROXY_RECOVERY_ATTEMPTS=1`，设为 `0` 关闭。恢复沿用原请求截止时间，失败候选不进入客户端历史或 Responses 缓存。
- 工具名称采用确定性别名，保留参数字段、Schema 约束、本地引用以及历史内容。代理不擅自补造缺失参数。
- 移除代理的 200,000 字符限制；工具定义与固定桥接规则在会话启动时注册，后续回合不再重复追加进用户消息。配置变化或恢复重建时重新注册。
- 增加 `X-Agy-Request-Id`、稳定错误代码、尝试次数、修复次数、用量完整性等诊断。按请求累计已知消耗，兼容旧用量记录。
- 增加阶段耗时日志、Perfetto/Chrome Trace 导出工具与原生日志启动脚本。诊断不记录完整业务正文、工具参数或密钥。

## 升级时的行为变化

**普通 Chat/Gemini 文本请求也采用受限客户端模式，流式正文在完整候选校验通过后交付。** 开始事件和心跳仍可先发送；长推理或长代码输出期间，客户端可能只收到心跳。任何业务内容交付后不自动重新生成。

服务器只允许 `finish` 和现有图片读取白名单；客户端工具由客户端执行。Gemini 内置搜索/代码执行等未支持能力明确拒绝。工具调用与独立结构化输出叠加仍不支持。

原生 AGY 的单条长输入截断、历史压缩后工具行为异常仍属于已观察到的兼容边界，本版没有宣称解决。删除代理字符限制并不取消 AGY 自身行为；配置只注册一次也不代表每次推理的配置 token 成本为零。详见[配置去重专项](../session-tool-configuration-fix-20261013.md)。

## 使用

仓库 Compose 已固定到 `v0.0.16`。已有部署先更新 Compose 中的镜像标签，再运行：

```bash
docker compose pull
docker compose up -d
```

沿用原数据卷；本次发布镜像不自动切换生产实例。完整能力与约束见[统一协议说明](../unified-client-protocols.md)，日志用法见[链路诊断](../latency-observability.md)。
