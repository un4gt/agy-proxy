## 行为变化

- finish 判定限定在当前输入轮次；内部补交计数不跨用户轮次累计，结构化输出
  不复用历史结果。偶发缺少 finish 时由原 CLI executor 在本轮内补交，最多
  三次；耗尽后保留用量并返回 `native_finish_exhausted`，不再外层重启重放。
- 更新概览、账号、登录和 CLI 更新页的布局、主题、表格与弹窗密度，适配桌面
  和移动尺寸；页面切换保留已加载数据，延迟显示骨架屏，减少加载闪烁。
- 账号 Usage 按基础模型合并思考档位，显示共享额度；不同模型不会因额度相同
  而被合并。账号目录使用匹配 CLI 版本的客户端标识，保留当前可用模型档位。
- 包含重新构建的 `app/static/app.css` 与 `app/static/assets/ui.js`，以及
  native.4–native.9 的大输入、HTTP/2 捕获、原生用量、图片读取和上游错误修复。

原生 CLI 仍固定为 1.4.0，SHA-256 为
`60e72242f07c131f75afcd9a9e425d6ee097a1a1b3190ea98ae78fa4180bbfa8`。
本地重建基础镜像带入 Python 3.12.16，上一版为 3.12.15。

## 验证

- 最终 Linux 镜像全套 pytest：779 passed，包含 PTY 用例。开发测试依赖与
  `tools/export_latency.py` 仅通过测试挂载提供，没有覆盖产品模块。
- 最终镜像的 57 个应用、原生模块与静态资源文件 SHA-256 均与提交快照一致。
- 固定 CLI、TLS 捕获和完整 Chat API 链路，配合隔离模拟上游：五个客户端请求、
  四次内部补交通过；保持同一会话，每个请求 attempts=1、repair_attempts=0。
- 本地 finish 边界七个场景通过；Node 22 模型分组测试 6 passed；TypeScript
  strict 检查及 Vite 构建通过。1440×1000 与 390×844 的十个控制台视图检查通过。

finish 补交验证使用模拟上游，不能代表真实上游长会话验收。上游在 ANY + finish
下仍可能返回纯文本；内部补交增加模型调用与等待，不保证持续缺少 finish 时成功，
也没有移除 stdin/stdout 或 GDB 依赖。
