# v0.0.20 — 独立模型额度分组

## 变更

- 账号额度路由按上游 quota group 拆分 scope：通用 Gemini（`gemini`）、Claude/GPT（`third-party`）以及独立模型组（`Gemini 4 Argon` → `gemini-4-argon`）。
- 独立组耗尽只阻断该组覆盖的模型；通用组会排除已有独立组的模型。Argon 耗尽不再误伤同一账号的 Flash/Pro，通用 Gemini 耗尽也不影响仍有余额的 Argon。
- 独立模型组的剩余比例 ≤1% 按不可用处理：上游可能把已耗尽的桶报成很小的正数（实测 Argon 为 0.55%）。通用组仍只认精确的 0，避免一个低子桶阻断整个厂商。
- 新独立组从上游 group 名称自动派生 scope，不需要再为每个模型硬编码列表；`Gemini Flash` 这类名称也能通过 token 匹配 `gemini-3.8-flash` 等版本化模型 ID。
- 旧版本写入的宽泛 `gemini` / `third-party` 记录仍按原语义读取；下一次额度快照会按实际分组替换或清除。
- 额度记录新增 `label`、`include`、`exclude` 元数据；面板的 `exhausted_scopes` 展示具体 scope。

## 验证

- `uv run pytest`：103 passed、2 skipped；仅剩 Windows 专有的 `chmod 0600` 断言失败（Linux 容器内通过）。
- 新增 `core/tests/test_account_pool.py`：Argon 独立 scope、通用组排除、未来独立组、版本化模型 ID 匹配、独立组 1% 近零保护、旧记录迁移、过期记录。
- 使用 aws-jp 933 账号的真实额度快照验证：Argon 剩余 0.55% 时只生成 `gemini-4-argon` 记录；Argon blocked=true，Flash/Pro/Claude blocked=false。
