# v0.0.17-native.6 — Usage 按基础模型显示额度

2026-10-22。

账号 Usage 原先逐条展示上游模型目录，把同一基础模型的 low、medium、high 等变体
画成多份额度。现在与概览模型列表保持一致：基础模型只占一项，变体作为附属标记，
共享一个剩余额度和刷新时间。没有相加额度，也没有根据额度数值相同而合并不同模型。

展示分组兼容上游旧模型 ID 别名和 Gemini Flash tiered 条目。没有已知额度时保留“额度未知”；
同组数据存在差异时，显示最低的已知剩余额度及对应刷新时间。
账号 API 继续返回完整目录，推理路由、模型启停和客户端可调用目录不变。
